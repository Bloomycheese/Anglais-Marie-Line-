# L'anglais de Marie Line

Application d'anglais hors ligne pour tablette Android : 4 niveaux (A1 à B2), conversations avec Emma, James et Grace, révision espacée, examens et certificats.

Adresse de l'application : https://bloomycheese.github.io/Anglais-Marie-Line-/

Installation sur la tablette : ouvrir l'adresse dans Google Chrome, puis toucher « Installer » (ou menu ⋮ puis « Ajouter à l'écran d'accueil »).
